# SpeakForward

안드로이드 Chrome에서 실행하고 홈 화면에 설치할 수 있는 무료 비즈니스 영어 PWA입니다.

**서비스 주소:** https://maincora44-wq.github.io/speakforward-opic/

버전 2.1.1: OPIc·질문 연습·상황 대화에서 음성 인식 문장이 반복 누적되는 문제를 수정했습니다. [원인과 검증](SPEECH-FIX.md)을 확인하세요. 홈의 **상황 대화 연습**, **저장 표현과 복습**, **나의 학습 기록**에서 새로운 기능을 시작할 수 있습니다. [구현 완료 범위](NEXT-COMPLETION.md)를 확인하세요.

## 휴대폰에서 시작하기

1. 안드로이드의 **Chrome**에서 위 주소를 엽니다. 메신저 안의 브라우저로 열었다면 Chrome에서 다시 여세요.
2. ‘질문의 순서’, ‘정중하게 요청하기’, ‘글로벌 감사 미팅’, ‘해외 법인과 협업’ 중 수업을 고릅니다.
3. 단어를 눌러 질문을 만들거나 영어로 직접 입력하고 **답안 확인**을 누릅니다.
   말하기를 연습하려면 **말로 답하기**를 누르세요. 인식된 문장을 확인·수정한 뒤 직접 **답안 확인**을 눌러야 제출됩니다. **조용히 · 직접 입력**으로 언제든 전환할 수 있어요.
4. 6문항을 마친 뒤 **오늘의 학습 완료**를 누르면 기기의 날짜를 기준으로 학습일이 기록됩니다.
5. 앱 안의 설치 버튼이 나타나면 누르거나 Chrome **⋮ → 홈 화면에 추가 / 앱 설치**를 사용합니다. 메뉴 이름과 설치 가능 여부는 브라우저에 따라 다릅니다.

이 결과물은 APK가 아닌 PWA입니다. Play Store 계정이나 APK 사이드로딩 없이 HTTPS 주소에서 사용할 수 있습니다. 실물 안드로이드 기기의 설치·마이크·음성 출력은 별도 확인이 필요합니다.

## 제공 기능

- Next 대시보드: 누적·오늘 XP, 100 XP마다 레벨 상승, 일일 퀘스트 3개, 완료/추천 단계가 표시되는 학습 경로. 원하는 수업을 자유롭게 선택할 수 있습니다.
- 안내형 상황 대화 3개: 감사 미팅, 환율 자료 설명, 과거 업무 경험. 대화당 4개 목표와 예시·규칙 힌트·다시 말하기·이어하기를 제공합니다. 자유 생성형 AI 대화는 연결되지 않았습니다.
- 예시 표현 12개 저장·듣기·자기확인 복습. 기억난 표현은 1·3·7일 뒤, 다시 연습할 표현은 10분 뒤 만납니다. 기한 전 연습은 복습 단계를 올리지 않습니다.
- 대화 완료당 하루 40 XP, 저장 표현 연습당 하루 5 XP. 같은 날 같은 항목의 중복 보상을 막고 질문 수업 XP와 합산합니다.
- 나의 학습: 질문 복습 태그와 실제 대화의 등록된 규칙 힌트를 모아 관련 수업과 복습을 추천합니다. 학습자의 자유 문장을 이해하는 모델이 추론한 점수는 아닙니다.
- 직접 작성한 30문항: 기존 질문 어순·정중한 요청·감사·협업 24문항에 환율 영어 6문항을 추가했습니다. 수업당 6문항, 목표 약 5분이며 시간제한은 없습니다.
- 금융 영어 수업: FinanceDataReader로 조회하고 FRED 원자료와 대조한 과거 USD/KRW를 활용합니다. 선택형·빈칸형·직접 입력·단어 순서로 연습하며 관측 기간과 `1 USD당 KRW` 단위를 표시합니다. 현재 환율을 제공하는 화면은 아닙니다.
- 문항별 등록 답안과 알려진 오류 예시를 사용하는 규칙 기반 피드백. 새 문장을 이해하는 AI 채점, 발음 점수, 공식 OPIc 등급을 제공하지 않습니다.
- 오답 태그와 복습: 오답은 10분 뒤, 독립된 다음 복습에서 정답이면 1·3·7일 순서로 예약합니다. 같은 수업의 재시도는 단계를 올리지 않습니다.
- 진행 중인 수업 이어하기, 첫 시도 정답 수, 일별 완료 기록과 연속 학습일. 복습 수업은 기한이 된 최대 6문항으로 구성되며 선택된 문항을 모두 제출하고 완료해야 기록됩니다.
- 기존 듣고 따라하기, OPIc 연습, 자기소개 작성, 녹음·다시 듣기. 기존 저장소 키를 보존했습니다.
- 글자 크기에 맞춰 줄바꿈되는 모바일 화면, 키보드 조작, 상태 안내, 선택적 음성 재생.
- 5분 질문 수업에서 선택적 음성 답변: 마이크 거부·미지원·네트워크 오류 안내, 인식 문장 수정, 직접 입력 전환. 잠시 멈춤·수업 이동·다른 메뉴·백그라운드 전환 시 음성 인식을 중지하며 늦게 도착한 인식 결과를 버립니다.

## 오프라인·음성·데이터

- 처음에는 인터넷에 연결해 페이지를 열고 하단의 **오프라인 텍스트 학습 준비 완료** 안내를 확인합니다. 이후 캐시가 유지되는 동안 텍스트 수업과 기존 화면을 오프라인으로 열 수 있습니다.
- 설치와 service worker는 HTTPS 또는 PC의 localhost에서 작동합니다. HTML 파일을 바로 여는 file:// 실행이나 일반 HTTP 휴대폰 LAN 주소는 설치·마이크 기능을 지원하는 배포 방식이 아닙니다.
- TTS 음성은 기기 설치 상태에 따라 달라지며 인터넷이 필요할 수 있습니다. 음성이 없으면 텍스트로 계속 학습할 수 있습니다.
- 음성 인식은 지원하는 브라우저에서 사용자가 시작할 때만 작동합니다. 브라우저 제공자의 네트워크를 사용할 수 있습니다. 미지원·권한 거부·오류 시 직접 입력을 사용하세요.
- Chrome 사이트 설정의 마이크가 ‘허용’이어도 음성 인식 서비스의 지원 여부나 연결 성공을 보장하지는 않습니다. 질문 수업의 안내 문구에서 원인을 확인하세요. 음성 인식은 받아쓰기이며 발음 평가가 아닙니다.
- 녹음은 마이크 권한을 허용한 경우 현재 세션에서 재생하며 업로드하지 않습니다. 화면을 숨기거나 학습 메뉴를 바꾸면 녹음을 중지합니다.
- Question Builder는 문항 ID, 결과, 오류 태그, 복습 일정, 진행 위치, 학습일만 기기의 localStorage에 저장합니다. 입력한 답안·녹음·음성 인식 내용은 새 모듈의 학습 기록에 저장하지 않습니다. 기존 자기소개 초안은 기존 방식대로 기기에 저장됩니다.
- 브라우저 데이터 삭제·기기 변경 시 기록이 사라질 수 있습니다. **학습 기록 내보내기 / 가져오기**의 v3 백업은 질문·XP·대화 진행·저장한 예시 표현과 복습 일정을 포함합니다. v1/v2 백업도 가져올 수 있으며 당시 형식에 없는 대화·표현 기록은 유지합니다. 자기소개와 녹음은 이 백업에 포함되지 않습니다.
- 저장소 사용 불가 시 안내문과 함께 세션 전용 모드로 동작합니다. 저장되지 않았는데 저장됐다고 표시하지 않습니다.
- 다른 탭의 질문/XP 기록 변경을 감지하면 이 창의 자동 저장을 멈춥니다. 현재 진행을 내보낸 뒤 다른 창을 닫고 새로고침하세요. 이전 상태로 저장된 기록을 덮어쓰지 않도록 하기 위한 안내입니다.
- 새 버전이 준비되면 ‘새 버전 적용’을 누르세요. 기존 수업 위치를 저장하고 새로고침합니다. 답안 입력 문장은 저장하지 않으므로 제출한 뒤 업데이트하세요.

## 개발·테스트·Windows 실행

현재 검증과 다음 개발 단계는 [검증 기록](VALIDATION.md), [FinanceDataReader 활용](FINANCE-DATA.md), [개발 단계](NEXT-ROADMAP.md)에 정리했습니다.

정적 HTML/CSS/JavaScript이며 실행 시 npm 패키지, API 키, 백엔드, 외부 CSS CDN이 필요하지 않습니다. Node는 개발용 미리보기와 테스트에만 필요합니다.

Node.js 24.15 이상(24 계열) 또는 22.22.2 이상(22 계열), 26 이상을 사용하세요.

```powershell
npm ci --ignore-scripts
npm test
npm start
```

PC에서 http://127.0.0.1:4173/speakforward-opic/ 를 여세요. Windows에서는 `start-preview.cmd`도 사용할 수 있습니다. 개발 의존성은 DOM 상호작용 테스트용 `jsdom`뿐이며 package-lock.json으로 고정됩니다. 개발 의존성 설치 없이 `npm start`로 미리보기를 시작할 수도 있습니다.

## 파일 구조와 유지보수

- `index.html`, `styles.css`: 모바일 화면 및 기존 모듈 마크업. 외부 리소스 없이 작동합니다.
- `core.js`: 순수 함수 채점, 로컬 날짜, 복습 일정, 상태 복구, 완료 처리. 브라우저와 Node 테스트에서 공유합니다.
- `lessons.js`: 원본 학습 콘텐츠. 의미 있는 콘텐츠 변경 시 문항 ID의 버전을 올려 이전 복습과 구분합니다.
- `app.js`: 새 학습 화면, 설치 안내, 저장·가져오기·내보내기.
- `practice-content.js`, `practice-core.js`, `practice.js`: 원본 상황 대화, 예시 비교·표현 복습·학습 메모리, UI 및 취소 가능한 음성 입력.
- `legacy.js`: 기존 네 가지 기능. 날짜를 로컬 날짜로 처리하고 음성·저장소 오류 및 녹음 정리를 보완했습니다.
- `manifest.webmanifest`, `sw.js`, `icons/`: 설치와 오프라인 앱 셸. 경로는 상대 경로이므로 GitHub Pages의 저장소 하위 경로를 지원합니다.
- `tests/`: 실제 학습 로직, DOM 흐름, 상태 복구와 PWA 파일 검증.
- `scripts/serve.cjs`: 의존성 없는 loopback 전용 개발 서버. 공개 운영 서버가 아닙니다.

앱 셸 파일을 변경해 배포할 때는 `sw.js`의 CACHE 버전을 반드시 올리세요. 동일 origin·앱 경로의 정적 리소스만 다루며 제3자 응답이나 학습자 내용을 캐시하지 않습니다. 새 버전은 사용자가 적용하거나 이전 탭이 닫힌 후 활성화됩니다.

## GitHub Pages 배포

사용자가 공개 배포를 승인한 2026-10-18 후속 요청에 따라 배포합니다. 저장소 Settings → Pages에서 **Deploy from a branch → main / (root)**를 사용합니다. 별도 빌드가 필요 없습니다. 변경은 기능 브랜치와 PR로 검증한 뒤 병합하며 Pages Actions 성공과 실제 HTTPS URL의 파일 응답을 확인합니다.

공개 저장소이므로 코드와 학습 문항은 공개됩니다. 계정 데이터, 브라우저 프로필, npm 캐시, 토큰, 녹음, 실제 업무 문서 또는 민감한 증빙을 커밋하지 마세요.

## 스픽 REA 조사와 구현

후속 요청에 따라 조사 대상을 **스픽(Speak)** 으로 변경했습니다. [실제 REA 실행 보고서](research/speak-rea/REA_EXECUTED_REPORT.md), [근거별 학습 흐름](research/speak-rea/USER_FLOW.md), [구현 명세](research/speak-rea/SPEAKFORWARD_SPEC.md)를 확인하세요.

REA 6.5.0으로 스픽 공개 웹 진입 페이지에 연결된 코드 두 파일을 실제 정적 분석해 Evidence ID를 확보했습니다. 공식 도움말에서 별도로 확인한 말하기·타이핑 전환과 재시도 흐름을 참고해, 기존 Question Builder에 독립적으로 작성한 음성 답변 기능을 추가했습니다. 로그인 후 수업·스픽의 AI 모델·발음 채점·복습 알고리즘을 실행 관찰한 결과는 아닙니다. 스픽과 제휴한 서비스가 아니며 스픽의 코드·문항·그래픽을 앱에 포함하지 않습니다.

29개 자동화 테스트가 통과했습니다. 실제 Android 마이크·음성 서비스·설치 상태의 실행은 이 환경에서 검증하지 못했습니다. 새 버전이 준비되면 앱 하단의 **새 버전 적용**을 눌러 업데이트하세요.

### 이전 조사 기록

Duolingo REA 페이지 조사는 브라우저 endpoint_unreachable로 중단됐습니다. 이 앱은 관찰이 완료된 Duolingo 재현품이 아닙니다. 사용자의 후속 ‘완성해서 안드로이드에서 작동’ 요청이 독립 설계 구현을 승인했으며, 별도 답변으로 공개 배포를 승인했습니다. Duolingo 코드·CSS·수업·캐릭터·그래픽·보호된 데이터는 사용하지 않았습니다.

기존 조사 Draft PR #2는 조사 차단 기록으로 유지합니다. 해당 문서의 관찰 미완료 상태를 성공으로 변경하지 않습니다.
