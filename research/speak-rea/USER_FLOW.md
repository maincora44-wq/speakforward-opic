# 스픽 근거와 SpeakForward 학습 흐름

상태: 스픽 공개 진입 코드 정적 분석 완료. 스픽 수업의 실행 관찰 0건. [실행 보고서](REA_EXECUTED_REPORT.md)에 Evidence ID와 범위를 기록했다.

## 스픽에서 확인한 범위

| 단계 | 근거 수준 | 확인 내용 / 남은 범위 |
|---|---|---|
| 공개 웹 진입 | HTTP + REA STATIC | 공개 HTML이 참조하는 진입 페이지와 layout 코드를 정적으로 파싱했다. 화면 전환은 실행하지 않았다. |
| 말하기·직접 입력 선택 | DOCUMENTED | [공식 모드 안내](https://help.speak.com/ko/articles/7969186)가 수업별 대체 입력 방식을 설명한다. 실제 버튼·계정별 사용 가능 여부는 UNKNOWN. |
| 말하기 → 텍스트 → 피드백 → 재시도 | DOCUMENTED | [프리톡 안내](https://help.speak.com/ko/articles/13182402)가 설명한다. 학습 계정의 실제 응답이나 지연 시간을 측정하지 않았다. |
| 표현 보관 | DOCUMENTED | [공식 보관 안내](https://help.speak.com/ko/articles/7969167)가 설명한다. 저장소 구조와 복습 알고리즘은 UNKNOWN. |

이는 스픽의 런타임 사용 기록이 아니다. 로그인 후 수업이나 Android 앱의 동작을 정적 코드에서 추정해 채우지 않는다.

## 이번에 구현한 독립 흐름

1. SpeakForward에서 6문항 수업 또는 기한이 된 복습을 선택한다.
2. 한국어 상황을 읽고, 필요하면 예시 질문을 듣는다.
3. 직접 입력·단어 선택으로 답하거나, **말로 답하기**를 직접 눌러 브라우저 음성 인식을 시작한다. 수업 시작만으로는 마이크를 요청하지 않는다.
4. 음성이 인식되면 답안 칸에 표시한다. 학습자는 문장을 수정할 수 있고 **답안 확인**을 직접 눌러야 제출된다. 말하기가 어려우면 **조용히 · 직접 입력**을 선택한다.
5. 문항에 등록된 답안·오류 예시와 비교한 피드백을 읽는다. 오답은 다시 연습하거나 다음 문항으로 진행한다. 발음 점수나 자유 문장에 대한 AI 평가를 표시하지 않는다.
6. 모든 문항을 제출하고 **오늘의 학습 완료**를 눌러 학습일을 기록한다. 문항 ID와 결과 메타데이터로 기존 복습을 예약한다. 받아쓴 문장·음성은 이 기록에 저장하지 않는다.

마이크 거부·미지원·음성 없음·서비스 연결 오류는 안내 후 직접 입력으로 계속한다. 잠시 멈춤, 수업 목록, 다른 메뉴, 직접 입력·단어 선택, 앱이 숨겨지거나 페이지를 나갈 때 인식을 중지한다. 이전 인식의 늦은 결과는 새 입력에 반영하지 않는다.

## 검증 수준

자동 DOM 테스트에서 위 입력·제출·전환·오류·정리 경로를 검증했다. SpeechRecognition은 모의 객체다. 실제 Android 권한 창·브라우저 음성 서비스·소리·발음 정확도·화면 렌더링·오프라인 설치 동작은 검증하지 않았다.
